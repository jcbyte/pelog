# <img src="assets/images//favicon.png" height="40"> &nbsp;PE Log

A logging app to give daily reminders for two configurable variables (P and E) on a repeating 28 day cycle.

## Run Locally

Install dependencies:

```bash
npm install
```

Start local development server:

```bash
npx expo start
```
